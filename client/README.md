# Task Board client

Small React + TypeScript (Vite) front end for the Task Board API: login, project list, and a three-column board with create and move actions.

```bash
npm install
npm run dev          # http://localhost:5173, proxies /api to http://localhost:8000
npm run test:e2e     # Playwright: login, create task, move task (API must be running)
```
